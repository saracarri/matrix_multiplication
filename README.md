# Matrix Multiplication — Big Data

**Course:** Big Data — Data Science and Engineering, ULPGC (2026/2027)

This repository contains four individual assignments exploring matrix multiplication performance, including execution time, memory usage, optimisation, parallelism and scalability.

## Assignments

| Assignment | Description | Technologies |
|---|---|---|
| [Assignment 1](assignment1/) | Basic implementations across programming languages | Python, Java, C |
| [Assignment 2](assignment2/) | Optimised dense multiplication and sparse CSR | C |
| [Assignment 3](assignment3/) | Parallel matrix multiplication with OpenMP | C, OpenMP |
| [Assignment 4](assignment4/) | Distributed matrix multiplication with MPI | C, MPI |

Each assignment contains its implementation, experimental results, figures, README with build and run instructions, and report.

**Note:** Later assignments reuse input data and results from earlier ones (`assignment1/data`, `assignment2/data`, `assignment3/results`). To reproduce the experiments, clone the entire repository and run the scripts from their respective assignment directories.
